EHOBA walkthrough

A scrubbed walkthrough of a desktop agent for the monthly hotel occupancy survey. It shows the processing flow without exposing hotel names, CUEs, survey values, or operational files.

Privacy note: every visible hotel identifier and survey value in this page is fictional or masked. The live operational app is not deployed publicly.
1

Load

The operator selects the month and imports the exported survey files. The app checks the expected 53-establishment frame before running the processor.

$ python ehoba_procesador.py --mes [month] --anio [year]
2

Validate

The agent applies fixed consistency checks: occupancy rates, tariff averages, traveler subtotals, incomplete submissions, and special operating states.
