English that marks itself

Practice material for secondary-school English, B1 to B1+. One rule holds all of it together: the page checks every answer on the spot, says what went wrong, and lets the student try again — so the feedback arrives while the student still cares about it. No accounts, no logins, nothing about the student leaves the browser.
